# WS2812B LED 점등 문제 — 컨텍스트 정리 (Claude 웹 질문용)

> 이 파일은 지금까지의 디버깅 과정을 정리한 것입니다.
> Claude 웹에 그대로 붙여넣고 질문하면 됩니다.

---

## 1. 프로젝트 개요

- **목적**: 욕실 바닥 타일의 수분을 감지해 LED로 미끄럼 위험 경고 (독거 노인 낙상방지)
- **구성**: 라즈베리파이 5 + ADS1115(ADC) + WS2812B LED 스트립
- **타일 수**: 4개 (현재는 단일 타일 PoC 진행 중)
- **타일당 LED**: 40개 (4타일 = 총 160개)

---

## 2. 하드웨어 환경

- **보드**: 라즈베리파이 5 (RP1 칩 / BCM2712)
- **LED**: WS2812B 5050 RGB 스트립, 타일당 40개
- **ADC**: ADS1115 4개 (I2C, 주소 0x48~0x4B)
- **LED 라이브러리**: `adafruit-circuitpython-neopixel` (RPi 5 전용 `adafruit-blinka-raspberry-pi5-neopixel` 백엔드, **RP1 PIO `/dev/pio0` 사용**)
- **전원**: 5V 3A 외부전원 + **LM2596S 강압 컨버터**(출력 가변)
- **LED 데이터 핀**: GPIO26 (물리 핀 37) 등 — 타일마다 독립 GPIO

### 스트립 패드
- `5V`, `−`(GND), `D0`(데이터 입력) 3개 패드
- 화살표(→) 방향 = 데이터 흐름 방향 (꼬리 쪽이 입력)

---

## 3. 소프트웨어 상태 (정상 확인됨)

- 4개 타일 NeoPixel 인스턴스 생성·`show()` 모두 **에러 없이** 동작
- `strace`로 확인: `/dev/pio0` 열고 PIO에 데이터 전송 ioctl 전부 성공
- **결론: 소프트웨어·드라이버·신호 출력은 100% 정상.** GPIO26에서 WS2812 파형이 실제로 나감.

---

## 4. 핵심 문제

**LED가 안정적으로 안 켜진다.** 증상이 들쭉날쭉:
- 어떤 때는 40~80개 켜짐
- 어떤 때는 2개만 켜짐
- 어떤 때는 전부 깜깜
- 한 픽셀만 켜진 채 안 꺼지기도 함

## 5. 지금까지 밝혀낸 원인 (2가지 겹침)

### 원인 ① 3.3V 데이터 레벨 부족
- WS2812B는 데이터 HIGH 인식 임계값 = **0.7 × VDD(전원전압)**
- VDD 5V → 임계값 3.5V 필요. 그런데 **RPi GPIO는 3.3V** → 임계값보다 낮아 데이터 오인식
- **LM2596S 출력을 4.282V로 낮췄더니** 임계값이 3.0V로 내려가 **LED가 켜지기 시작함** → 레벨 문제임이 확인됨
- 하지만 마진이 0.3V(3.3V − 3.0V)로 빠듯해서 여전히 불안정

| VDD | 임계값(0.7×VDD) | RPi 3.3V와의 마진 |
|-----|----------------|------------------|
| 5.0V | 3.5V | **−0.2V (실패)** |
| 4.28V (현재) | 3.0V | 0.3V (빠듯) |
| 4.0V | 2.8V | 0.5V |
| 3.8V | 2.66V | 0.64V |

### 원인 ② 데이터선이 너무 김 (1.5m)
- WS2812B 데이터는 800kHz 고속 신호 → 1.5m 점퍼선은 신호 엣지가 뭉개지고 반사로 왜곡
- 특히 3.3V 빠듯한 레벨과 겹쳐서 **첫 LED가 신호를 못 읽음**
- 체인의 **첫 LED**가 관문: 첫 LED만 통과하면 그 LED가 신호를 VDD 전압으로 재생성해 나머지는 정상 동작
- 지금은 첫 LED가 아슬아슬하게 읽어서 1~2픽셀만 잡고 중간에 깨짐

**→ 두 원인이 겹쳐 신호가 "경계선"에 걸려 됐다 안 됐다 한다.**

## 6. 제안된 해결책

### A. 부품 없이 (LM2596S만 사용)
1. LM2596S 출력을 **3.8V로 낮추기** (레벨 마진 2배로)
2. **데이터선 1.5m → 20cm 이내로 단축** (RPi를 스트립 가까이)
3. 전원선(5V·GND)만 길게, 데이터선은 짧게
4. GND를 짧고 굵게 한 점으로 묶기

### B. 레벨시프터 사용 (정석)
- **74AHCT125** 또는 **74HCT245**로 데이터선 3.3V→5V 깨끗하게 승압
- 5V 신호는 긴 선도 잘 버팀

### C. 손에 있는 BSS138 1개로 레벨시프터 자작
- BSS138 = N채널 MOSFET. 저항 2개 추가하면 1채널 레벨시프터 (NXP AN10441 표준 회로)
- **회로:**
  ```
           3.3V                    5V
            │                       │
           [R1]                    [R2]
            │                       │
  RPi GPIO26 ─┴─ Source   Drain ─┴─ WS2812 D0
                (2번)     (3번)
                    │
                  Gate(1번) ── 3.3V
  ```
- Gate(1) → 3.3V / Source(2) → GPIO26 + R1풀업(→3.3V) / Drain(3) → D0 + R2풀업(→5V)
- **주의: 풀업저항 R1, R2 = 1k~2.2kΩ 권장** (800kHz 고속이라 10kΩ은 너무 느려서 안 될 수 있음)
